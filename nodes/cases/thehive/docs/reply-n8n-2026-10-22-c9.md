## 2. `containment-action` on an alert: yes

Custom fields are defined once for alerts and cases, so `containment-action` can be set on the alert. Two details:

- **If the alert is already in a case**, set it on the case too. Otherwise the case keeps the template's default `none`.
- **If the case is created after the action**, TheHive copies the alert's custom fields into the case. Please check in the dry run that the template's default `none` doesn't override `ip-blocked`. If it does, set it on the case after promotion.
