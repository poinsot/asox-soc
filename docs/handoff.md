## Gotchas learned

- **Memory limits (D40):** size from the anon peak in the cgroup's `memory.stat` (`/sys/fs/cgroup/system.slice/docker-<id>.scope/`), through start + bootstrap + activity + idle; `docker stats`/`memory.peak` include page cache (the Wazuh manager fills ~450 MiB of reclaimable log cache and sits at its limit harmlessly). With swap allowed, undersized limits only showed as swap; now `memswap_limit` = `mem_limit`, so watch for OOM kills and Java/Node "out of memory" instead. Elasticsearch 8 and TheHive use ~0.5–1 GB beyond their heap. Grafana 13 leaked per browser session (pinned 12.4). n8n 2.x needs an explicit Node heap (`N8N_HEAP`, 320 MB minimum on `low`).
- **Healthchecks must mean "ready"**, not "process up": the Wazuh manager check covers the API and core daemons (A27); the lab agent waits for its post-enrollment reload (A31); cases services use `cqlsh`, cluster health and `/api/status` (A51). `soc.sh up --wait` relies on this.
- **MISP:** API keys are 40 alphanumeric characters (not our secret format); misp-nginx needs a mounted certificate; first start ~2 min; misp-core peaks at start-up while loading galaxies/taxonomies. Cortex caches analyzer results per observable: use `force: true` to get a real new job (A61).
- **Cortex and the Docker socket:** never run the Cortex container as root: its entrypoint chowns the (host's) socket (A50). Cortex config keys `docker.container.*` exist in the code but not in the docs (A49).
- **TheHive API:** connector config via `PUT /api/v1/admin/config/cortex` needs `statusCheckInterval`, `refreshDelay`, `maxRetryOnError`; server status is in `GET /api/v1/status` → `.connectors.cortex`; license quotas in `.license.quotas`. User type (Normal/Service) can't be changed after creation.
- **Wazuh manager restart:** the image's init aborts on `docker restart` ("0-wazuh-init: exited 1", harmless now); `entrypoint-scripts/05-restart-fixes.sh` redoes the config copy (A26). Config under `/wazuh-config-mount` is copied at every start; deleted files stay in the volume.
- **Re-enrollment:** a fresh agent with an existing name is refused; `soc.sh reset lab` removes the old registration (A30).
- **Wazuh API RBAC:** changes revoke tokens issued in the same second (retry, A18); custom policies identical to built-ins are rejected.
- **Wazuh certs:** the cert tool only accepts dotted DNS names → indexer is `wazuh.indexer` (D32).
- **n8n:** UI login rate-limited (5/window) → scripts use `N8N_API_KEY` (public API). CLI import runs in a one-off container; activation via API, then wait for webhook registration (~0.1 s, A44). Never put secrets in n8n's environment (D37).
- **Grafana:** OpenSearch plugin health check needs the daily index pattern (D35); `GF_INSTALL_PLUGINS` + preinstall disabled for pinning only the plugin (A35).
- **Secret scan:** gitleaks flags literal credentials in `curl -u` / `-H` even in healthchecks or probes; use variables or client certs.
- **Shell waits:** the harness blocks leading `sleep N`; use `timeout N bash -c 'until ...; do sleep 3; done'`. Background samplers started with `nohup ... &` die with the shell; use a tracked background task.
- **Local CI:** `scripts/ci-checks.sh all` (compose config both modes, shellcheck, JSON/XML, gitleaks) before each commit.
